# 前言 {.unnumbered}

很多人恋爱受挫，不是因为不够好，而是因为把太多赌注压在“表白”这一个瞬间：暧昧几个月，鼓足勇气说出口，然后等待一场“定生死”的答复。

美国年轻人的恋爱路径提供了另一种思路：**先约会，再确认**。两个人用一杯咖啡、一次散步这样低成本的方式见面，在多次约会中逐步了解彼此，等双方的好感都已经很明确时，再用一次平静的对话把关系定下来。约会不等于承诺，拒绝也不等于失败。

这本书按真实恋爱进程展开：从心态准备、认识渠道、约会软件、发出邀约、第一次约会、约会后的跟进，到多次约会、身体亲密与同意、确认关系、日常相处、沟通与矛盾、见家长、同居、订婚与婚礼、分手，再到中国人与美国人约会的跨文化专题，最后是总复习和关于身体亲密渐进与边界的专题。

学习美国方式的目的，不是“换一套标准”，也不是认为美国方式更先进。美国方式降低了试错成本，但也带来了承诺困难、关系模糊和约会倦怠；中国方式更强调确定性和承诺，但也容易造成表白压力和过早投入。本书希望做的，是**扩充你的工具箱**：理解背后的原理，然后在你自己的生活中——无论在国内还是海外——选择性地使用其中最有用的部分。

贯穿全书的只有一句话：

> 在每一个关键时刻，把你心里想的、需要的、不愿意的，清楚而温和地说出来；然后看对方的行动，而不只是听对方的话。

# 使用说明 {.unnumbered}

**阅读顺序。** 第 0–17 章按恋爱的时间顺序排列，建议从头读起。第 18 章是专题，讨论不同阶段的身体亲密、过夜细节与边界，覆盖美国与国内语境，适合在读完第 5、7、8 章之后阅读。

**每章的固定结构。** 除总复习外，每章都由以下模块组成：

1. **本章要点**：3–5 条核心结论；
2. **详细讲解**：每个小节按“美国常见做法 → 背后的原因 → 具体怎么做”展开；
3. **典型时间线或流程**：大致参考，不是硬性规则；
4. **中美对比表**：中国常见做法、美国常见做法与差异原因；
5. **实用英文表达**：英文、中文意思、使用场景与语气说明；
6. **完整对话示例**：每句台词后附灰色的“潜台词”批注；
7. **常见误区与雷区**：中国人最容易出错的地方；
8. **安全提醒**；
9. **本章小练习**：题目在前，参考答案与解释另起一栏放在章末。

**如何练习。** 建议先独立写出练习答案，再对照参考答案。对话示例可以朗读，或者找朋友分角色练习。附录 A 汇总了全书的英文表达，附录 B 汇总了求助资源，附录 C 是术语表。
