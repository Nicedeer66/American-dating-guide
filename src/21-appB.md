# 附录 B　求助资源汇总 {#appB}

::: chapterlead
以下资源均在正文各章中提到过，集中列出以便查阅。号码与服务可能变化，使用前请以官方信息为准。遇到紧急危险，请优先拨打紧急电话。
:::

## 一、紧急情况

| 地区 | 号码 | 用途 |
|---|---|---|
| 中国 | 110 | 报警：人身威胁、暴力、跟踪、诈骗 |
| 中国 | 120 | 医疗急救 |
| 美国 | 911 | 报警、医疗急救、消防 |

## 二、心理危机与情绪支持

| 地区 | 资源 | 说明 |
|---|---|---|
| 美国 | 988（拨打或发短信） | 全国心理危机与自杀预防热线，24 小时 |
| 美国 | 大学学生心理咨询中心（counseling center） | 在校生通常可免费或低价使用 |
| 中国 | 学校心理健康教育与咨询中心 | 许多高校提供免费咨询 |
| 中国 | 当地心理援助热线 | 各地号码不同，可通过当地卫生健康部门或学校查询 |

## 三、家庭暴力、约会暴力与控制型关系

| 地区 | 资源 | 说明 |
|---|---|---|
| 美国 | National Domestic Violence Hotline：1-800-799-7233；或发短信 START 到 88788 | 全国家暴求助热线，24 小时保密，支持多语言 |
| 美国 | love is respect：发短信 LOVEIS 到 22522 | 面向年轻人的约会暴力求助项目 |
| 美国 | 保护令（protective order / restraining order） | 向法院申请，程序各州不同 |
| 中国 | 12338 | 全国妇联妇女维权公益服务热线 |
| 中国 | 人身安全保护令 | 依《反家庭暴力法》向法院申请；共同生活的人之间的暴力参照适用 |
| 中国 | 学校辅导员、保卫处、心理咨询中心 | 在校学生可求助 |

## 四、性侵犯与性骚扰

| 地区 | 资源 | 说明 |
|---|---|---|
| 美国 | RAINN 全国性侵热线：1-800-656-4673 | 24 小时保密支持 |
| 美国 | 学校 Title IX 办公室 | 处理校园性骚扰与性侵投诉 |
| 中国 | 110、医院、学校心理咨询中心 | 优先确保安全并尽快就医，保留证据 |

**发生非自愿性行为后**：先离开危险环境，联系信任的人；尽快就医（紧急避孕、预防感染），如考虑报案，就医前尽量不要洗澡或更换衣物；**这不是你的错**。

## 五、网络诈骗与性勒索

| 地区 | 资源 | 说明 |
|---|---|---|
| 中国 | 110、网信部门举报渠道 | 杀猪盘、刷单、交友引流等 |
| 美国 | FBI IC3 网络犯罪投诉中心 | 浪漫诈骗、投资诈骗、性勒索 |
| 通用 | 约会软件内的举报功能 | 发现可疑账号立即举报 |

**遭遇性勒索时**：不要付钱，保留证据，立即报警并在平台举报。

## 七、法律与移民问题

| 事项 | 建议渠道 |
|---|---|
| 移民、签证、绿卡 | 执业移民律师；美国移民局（USCIS）与美国国务院官方网站 |
| 涉外婚姻登记 | 当地有权办理涉外婚姻登记的民政部门 |
| 同居、婚前财产、离婚 | 执业律师 |
| 身份依赖下遭遇家暴（美国） | 家暴援助机构与移民律师（如 VAWA 自行申请途径） |
